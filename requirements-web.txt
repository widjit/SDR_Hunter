# SDR Hunter — web-mode-only Python dependencies
#
# This is the trimmed dependency set used by the headless web server
# (``python main.py --web``) and the Docker image (see Dockerfile / DOCKER.md).

# audio-output libraries (sounddevice, PyAudio) — none of which are needed by
# the ``--web`` code path, and which would only bloat a headless server image.
#
# SoapySDR Python bindings are provided by the system packages (installed via
# apt in the Docker image), NOT pip. The app falls back to a synthetic mock
# device when SoapySDR / hardware is absent (SDRHUNTER_FORCE_MOCK=1).
#
# For the full desktop experience use requirements.txt instead.
